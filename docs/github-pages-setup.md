# GitHub Pagesの初期設定

1. GitHubでこのリポジトリを開きます。
2. 上部の「Settings」を開きます。
3. 左側の「Pages」を開きます。
4. 「Build and deployment」の「Source」で `Deploy from a branch` を選びます。
5. Branchは `main`、フォルダは `/(root)` を選びます。
6. 「Save」を押します。

公開には数分かかる場合があります。公開URLは次の形式です。

```text
https://20230104curl.github.io/bunmyaku-shobu/
```

以後は `main` に反映した変更が自動で公開されます。
