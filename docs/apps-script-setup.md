# Google Apps Scriptの初期設定

## 1. コードを貼り付ける

1. 管理用スプレッドシートを開きます。
2. 上部メニューの「拡張機能」→「Apps Script」を開きます。
3. 最初から入っているコードをすべて削除します。
4. このリポジトリの `apps-script/Code.gs` の内容をすべて貼り付け、保存します。

## 2. 初期設定を実行する

1. 画面上部の関数選択で `setupWorkbook` を選びます。
2. 「実行」を押します。
3. 初回だけGoogleの権限確認が表示されるので、このスプレッドシートへのアクセスを許可します。
4. 「初期設定が完了しました」と表示されたら完了です。

## 3. ウェブアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」を押します。
2. 種類は「ウェブアプリ」を選びます。
3. 「次のユーザーとして実行」は「自分」にします。
4. 「アクセスできるユーザー」は「全員」にします。
5. 「デプロイ」を押し、表示された `/exec` で終わるURLを控えます。

## 4. 生徒用画面へ接続する

`assets/config.js` の次の部分を、控えたウェブアプリURLに変更します。

```js
apiUrl: "https://script.google.com/macros/s/（デプロイID）/exec"
```

Apps Scriptを変更した場合は、「デプロイを管理」から既存デプロイを編集し、新しいバージョンを反映します。
