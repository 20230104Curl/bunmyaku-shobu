# 文脈勝負

小学6年生・中学受験向けの「6段落並べ替え」トレーニングです。

## 構成

- GitHub Pages：生徒用画面
- Googleスプレッドシート：生徒名簿・31問・正解・実施記録・集計
- Google Apps Script：ID確認・問題配信・正誤判定・記録保存

正解順と誤答解説はGoogleスプレッドシート側だけに置き、公開リポジトリには含めません。

## 主な仕様

- 2026年10月1日〜31日、1日1問
- 読解3分＋並べ替え60秒、合計4分
- 本文は解答時間中も表示
- 1日1回のみ。提出済み問題への再挑戦は不可
- 誤答時は最重要のつまずき1か所だけを解説
- テスト用ID `12345678` は実施期間外でも即時解答でき、正式記録の保存確認に利用可能

## 初期設定

1. 管理用Googleスプレッドシートを開きます。
2. [Apps Scriptの設定](docs/apps-script-setup.md)を行います。
3. ウェブアプリURLを `assets/config.js` に設定します。
4. [GitHub Pagesの設定](docs/github-pages-setup.md)を行います。

## 管理用スプレッドシート

管理は次のシートで行います。

- `生徒名簿`
- `問題一覧`
- `実施記録`
- `個人検索`
- `全体ダッシュボード`
- `実施状況`（対象日数に対する実施日数・正解数・各率）
- `要フォロー生徒`（前日までに3日以上連続して未実施の生徒）

`問題一覧`には正解と解説が含まれるため、生徒には共有しないでください。
